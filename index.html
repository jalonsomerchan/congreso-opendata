Congreso Open Data · API estática JSON

Datos del Congreso listos para consumir desde cualquier app

Este repositorio convierte parte del Open Data del Congreso de los Diputados en JSON versionado: votaciones, iniciativas, intervenciones, diputados e índices por legislatura y año.

Ver endpoints Ejemplos GitHub

Estado de los datos

Este panel intenta leer automáticamente los índices generados en data/congreso.

Cómo funciona

No hay servidor propio. Es una API estática: GitHub Actions ejecuta los crawlers, guarda los datos en data/congreso y cualquier web, script o backend puede leer esos JSON por HTTP.

  • Actualización: el workflow se ejecuta manualmente y cada 30 minutos.
  • Formato común: los ficheros de detalle tienen metadata generado por este repo y data con la respuesta oficial del Congreso.
  • Índices principales: cada bloque tiene index.json con todos los recursos conocidos y latest.json con los últimos cambios de crawler.
  • Índices derivados: cada bloque tiene índices por legislaturas y por anios, con index.json, latest.json y alias lastest.json.

Endpoints disponibles

EndpointContenido
data/congreso/legislaturas.jsonResumen global de legislaturas disponibles en todos los bloques.
data/congreso/{bloque}/index.jsonÍndice principal del bloque. Bloques: votaciones, iniciativas, intervenciones, diputados.
data/congreso/{bloque}/latest.jsonCambios detectados por el crawler en la última ejecución con cambios.
data/congreso/{bloque}/legislaturas/index.jsonLista de legislaturas detectadas para ese bloque.
data/congreso/{bloque}/legislaturas/{legislatura}/index.jsonTodos los registros de un bloque para una legislatura. Ejemplo: votaciones/legislaturas/leg15/index.json.
data/congreso/{bloque}/legislaturas/{legislatura}/latest.jsonÚltimos registros disponibles de esa legislatura, ordenados por fecha o timestamp.
data/congreso/{bloque}/anios/index.jsonLista de años detectados para ese bloque.
data/congreso/{bloque}/anios/{anio}/index.jsonTodos los registros de un bloque para un año. Ejemplo: votaciones/anios/2026/index.json.
data/congreso/{bloque}/anios/{anio}/latest.jsonÚltimos registros disponibles de ese año.
data/congreso/{bloque}/.../lastest.jsonAlias de compatibilidad de latest.json.

Rutas de detalle por bloque

BloqueDetalleInformación disponible
Votacionesdata/congreso/votaciones/{legislatura}/{sesion}/{fecha}/{votacion}.jsonLegislatura, sesión, fecha, número de votación, URL oficial y respuesta JSON oficial.
Iniciativasdata/congreso/iniciativas/{dataset}/{timestamp}.jsonDatasets oficiales: iniciativas legislativas aprobadas, proyectos, proposiciones y reformas de estatuto.
Intervencionesdata/congreso/intervenciones/{recurso}/{timestamp-o-hash}.jsonRecursos JSON, CSV o XML detectados desde el buscador de intervenciones, normalizados como JSON.
Diputadosdata/congreso/diputados/{dataset}/{timestamp}.jsonDiputados activos, diputados por legislatura, diputadas en todas las legislaturas y declaraciones de intereses.

Estructura de los JSON

Ejemplo de índice por legislatura

{
  "generated_at": "2026-06-16T10:00:00+00:00",
  "section": "votaciones",
  "group": { "id": "Leg15", "slug": "leg15", "type": "legislature" },
  "total_records": 123,
  "votes": {
    "leg15-sesion185-20260611-votacion001": {
      "id": "leg15-sesion185-20260611-votacion001",
      "path": "data/congreso/votaciones/leg15/sesion185/20260611/votacion001.json",
      "grouping": { "legislatures": ["Leg15"], "years": ["2026"] }
    }
  }
}

Ejemplo de detalle

{
  "metadata": {
    "id": "...",
    "source_url": "...",
    "captured_at": "2026-06-16T10:00:00+00:00"
  },
  "data": {
    "...": "Respuesta oficial del Congreso"
  }
}

El bloque metadata lo genera este repositorio. El bloque data conserva la estructura oficial del Congreso, así que sus campos pueden variar según el recurso.

Ejemplos de uso

JavaScript: obtener legislaturas disponibles

const base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
const legislaturas = await fetch(base + 'data/congreso/legislaturas.json').then(r => r.json());
console.log(legislaturas.legislatures);

JavaScript: últimas votaciones de la legislatura 15

const latest = await fetch(base + 'data/congreso/votaciones/legislaturas/leg15/latest.json').then(r => r.json());
const first = latest.latest_records[0];
const detail = await fetch(base + first.path).then(r => r.json());
console.log(detail.metadata, detail.data);

PHP: iniciativas de un año

<?php
$base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
$json = file_get_contents($base . 'data/congreso/iniciativas/anios/2026/index.json');
$data = json_decode($json, true);
print_r($data);
?>
