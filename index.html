Congreso Open Data · API estática JSON

Datos del Congreso listos para consumir desde cualquier app

Este repositorio convierte parte del Open Data del Congreso de los Diputados en ficheros JSON versionados: votaciones, iniciativas e intervenciones.

Ver endpoints Ejemplos GitHub

Estado de los datos

Este panel intenta leer automáticamente los índices generados en data/congreso.

Cómo funciona

No hay servidor propio. Es una API estática: GitHub Actions ejecuta los crawlers, guarda los datos en data/congreso y cualquier web, script o backend puede leer esos JSON por HTTP.

  • Actualización: el workflow se ejecuta manualmente y cada 30 minutos.
  • Formato común: los ficheros de detalle tienen metadata generado por este repo y data con la respuesta oficial del Congreso.
  • Índices: cada bloque tiene index.json con todos los recursos conocidos y latest.json con los últimos cambios.
  • Histórico: iniciativas e intervenciones guardan snapshots cuando cambia el contenido; votaciones usa rutas estables por legislatura, sesión, fecha y votación.

Ejemplo de detalle

{
  "metadata": {
    "id": "...",
    "source_url": "...",
    "captured_at": "2026-06-16T10:00:00+00:00"
  },
  "data": {
    "...": "Respuesta oficial del Congreso"
  }
}

El bloque metadata lo genera este repositorio. El bloque data conserva la estructura oficial del Congreso, así que sus campos pueden variar según el recurso.

Qué información hay disponible

Votaciones

Votaciones nominales y recursos JSON oficiales publicados por sesión plenaria.

  • Legislatura, sesión, fecha y número de votación.
  • URL y fichero oficial.
  • Respuesta oficial completa dentro de data.

Iniciativas

Datasets de iniciativas publicados en OpenData.

  • Iniciativas legislativas aprobadas.
  • Proyectos y proposiciones de ley.
  • Propuestas de reforma de estatuto y otros datasets oficiales.

Intervenciones

Recursos detectados desde el buscador oficial.

  • Enlaces JSON, CSV o XML si aparecen expuestos.
  • Recursos añadidos con INTERVENCIONES_EXTRA_URLS.
  • Contenido normalizado como JSON.

Ejemplos de uso

JavaScript: índice de votaciones y detalle

const base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
const index = await fetch(base + 'data/congreso/votaciones/index.json').then(r => r.json());
const vote = Object.values(index.votes || {}).at(-1);
const detail = await fetch(base + vote.path).then(r => r.json());
console.log(detail.metadata, detail.data);

PHP: leer datasets de iniciativas

<?php
$base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
$index = json_decode(file_get_contents($base . 'data/congreso/iniciativas/index.json'), true);
foreach ($index['datasets'] ?? [] as $dataset) {
    $json = json_decode(file_get_contents($base . $dataset['latest_path']), true);
    echo $dataset['official_name'] . PHP_EOL;
}
