Congreso Open Data · API estática JSON

Datos del Congreso listos para consumir desde cualquier app

Este repositorio transforma el Open Data del Congreso de los Diputados en JSON versionado: votaciones, iniciativas, intervenciones, diputados, legislaturas disponibles e índices por legislatura y año.

Ver endpoints Diputados Ejemplos GitHub

Estado de los datos

Este panel intenta leer automáticamente los índices generados en data/congreso. Si todavía no se ha ejecutado el Action, algunas tarjetas aparecerán como pendientes.

Cómo funciona

No hay backend propio. Es una API estática: GitHub Actions ejecuta crawlers, descarga o normaliza los recursos públicos del Congreso y guarda JSON dentro de data/congreso. Después puedes consumirlos desde GitHub Pages o desde raw.githubusercontent.com.

  • Actualización: el workflow se ejecuta manualmente y también de forma programada cada 30 minutos.
  • Datos originales: cada fichero de detalle conserva la respuesta oficial dentro de data y añade metadatos propios dentro de metadata.
  • Índices principales: cada bloque tiene index.json y latest.json.
  • Agrupaciones: cada bloque genera índices por legislaturas y por anios.
  • Alias: además de latest.json, se genera lastest.json como alias compatible con la errata frecuente.

Bloques disponibles

Votaciones

Votaciones del Pleno detectadas en la página oficial de OpenData, con legislatura, sesión, fecha y número de votación.

Iniciativas

Datasets oficiales de iniciativas legislativas: aprobadas, proyectos de ley, proposiciones y reformas de estatuto.

Intervenciones

Recursos OpenData detectados desde el buscador de intervenciones. Puede quedar vacío si el Congreso no publica enlaces directos sin interacción.

Diputados

Datasets de diputados activos, diputados por legislatura, diputadas históricas y declaraciones de intereses.

data/congreso/{bloque}/anios/{anio}/index.jsonTodos los registros de un bloque para un año. Ejemplo: data/congreso/iniciativas/anios/2026/index.json.

Legislaturas disponibles

El endpoint global data/congreso/legislaturas.json agrega todas las legislaturas encontradas en los bloques disponibles. Cada legislatura incluye su id, slug, total de registros y, dentro de sections, las rutas de índice y últimos registros por bloque.

{
  "generated_at": "2026-06-16T10:00:00+00:00",
  "generated_by": "scripts/build_congreso_indexes.py",
  "total_legislatures": 1,
  "legislatures": [
    {
      "id": "Leg15",
      "slug": "leg15",
      "total_records": 123,
      "sections": {
        "votaciones": {
          "total_records": 100,
          "index_path": "data/congreso/votaciones/legislaturas/leg15/index.json",
          "latest_path": "data/congreso/votaciones/legislaturas/leg15/latest.json",
          "lastest_path": "data/congreso/votaciones/legislaturas/leg15/lastest.json"
        }
      }
    }
  ]
}

Diputados

El bloque diputados funciona igual que el resto: tiene índice principal, últimos cambios, agrupaciones por legislatura y agrupaciones por año.

  • data/congreso/diputados/index.json · todos los datasets de diputados detectados.
  • data/congreso/diputados/latest.json · últimos datasets descargados o actualizados.
  • data/congreso/diputados/legislaturas/index.json · legislaturas disponibles en datasets de diputados.
  • data/congreso/diputados/anios/index.json · años disponibles en datasets de diputados.

Estructura de los JSON

Índice principal de bloque

{
  "updated_at": "2026-06-16T10:00:00+00:00",
  "source": "https://www.congreso.es/...",
  "total_datasets": 4,
  "datasets": {
    "diputados-activos-20260616050022": {
      "id": "diputados-activos-20260616050022",
      "path": "data/congreso/diputados/diputados-activos/20260616050022.json",
      "source_url": "https://www.congreso.es/...json",
      "first_seen_at": "2026-06-16T10:00:00+00:00"
    }
  }
}

Índice por legislatura o año

{
  "generated_at": "2026-06-16T10:00:00+00:00",
  "generated_by": "scripts/build_congreso_indexes.py",
  "section": "votaciones",
  "group": { "id": "Leg15", "slug": "leg15", "type": "legislature" },
  "total_records": 123,
  "votes": {
    "leg15-sesion185-20260611-votacion001": {
      "id": "leg15-sesion185-20260611-votacion001",
      "path": "data/congreso/votaciones/leg15/sesion185/20260611/votacion001.json",
      "grouping": { "legislatures": ["Leg15"], "years": ["2026"] }
    }
  }
}

Fichero de detalle

{
  "metadata": {
    "id": "...",
    "source_url": "...",
    "captured_at": "2026-06-16T10:00:00+00:00"
  },
  "data": {
    "...": "Respuesta oficial del Congreso"
  }
}

Los nombres exactos de las claves de registros cambian por bloque: votes en votaciones, datasets en iniciativas y diputados, y resources en intervenciones.

Ejemplos de uso

JavaScript: obtener legislaturas disponibles

const base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
const legislaturas = await fetch(base + 'data/congreso/legislaturas.json').then(r => r.json());
console.log(legislaturas.legislatures);

JavaScript: últimas votaciones de la legislatura 15

const latest = await fetch(base + 'data/congreso/votaciones/legislaturas/leg15/latest.json').then(r => r.json());
const first = latest.latest_records[0];
const detail = await fetch(base + first.path).then(r => r.json());
console.log(detail.metadata, detail.data);

JavaScript: iniciativas de 2026

const iniciativas2026 = await fetch(base + 'data/congreso/iniciativas/anios/2026/index.json').then(r => r.json());
console.log(Object.values(iniciativas2026.datasets));

JavaScript: datasets de diputados disponibles

const diputados = await fetch(base + 'data/congreso/diputados/index.json').then(r => r.json());
console.log(Object.keys(diputados.datasets));

PHP: leer últimos registros de un año

<?php
$base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';
$json = file_get_contents($base . 'data/congreso/votaciones/anios/2026/latest.json');
$data = json_decode($json, true);
print_r($data['latest_records']);
?>
