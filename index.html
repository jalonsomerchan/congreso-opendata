Cómo funciona

No es una API REST con servidor. Es una API estática: GitHub Actions ejecuta los crawlers, guarda los datos en data/congreso y cualquier web, script o backend puede leer esos JSON por HTTP.

  • Actualización: el workflow se ejecuta manualmente y de forma programada cada 30 minutos.
  • Formato: cada fichero descargado conserva la respuesta oficial dentro de data y añade metadatos propios en metadata.
  • Índices: cada bloque tiene un index.json con todos los recursos conocidos y un latest.json con los últimos cambios detectados.
  • Histórico: las iniciativas e intervenciones guardan snapshots cuando cambia el hash del contenido; las votaciones se guardan con ruta estable por legislatura, sesión, fecha y votación.

Endpoints disponibles

Bloque Endpoint Contenido
Votaciones data/congreso/votaciones/index.json Índice de todas las votaciones conocidas. Incluye total_votes, generated_at, last_run y el mapa votes.
Votaciones data/congreso/votaciones/latest.json Votaciones nuevas o actualizadas en la última ejecución con cambios.
Votaciones data/congreso/votaciones/{legislatura}/{sesion}/{fecha}/{votacion}.json Detalle de una votación concreta. Ejemplo de ruta: data/congreso/votaciones/leg15/sesion185/20260611/votacion001.json.
Iniciativas data/congreso/iniciativas/index.json Índice de datasets de iniciativas encontrados en Open Data: iniciativas legislativas aprobadas, proyectos de ley, proposiciones de ley y otros ficheros que publique el Congreso.
Iniciativas data/congreso/iniciativas/latest.json Datasets de iniciativas nuevos o actualizados en la última ejecución con cambios.
Iniciativas data/congreso/iniciativas/{dataset}/latest.json Última versión conocida de un dataset de iniciativas. El nombre del dataset se obtiene del campo id del índice.
Iniciativas data/congreso/iniciativas/{dataset}/{timestamp}.json Snapshot histórico de un dataset de iniciativas. El timestamp viene del fichero oficial del Congreso cuando está disponible.
Intervenciones data/congreso/intervenciones/index.json Índice de recursos OpenData de intervenciones detectados. Puede estar vacío si el buscador del Congreso no expone enlaces estáticos en el HTML inicial.
Intervenciones data/congreso/intervenciones/latest.json Recursos de intervenciones nuevos o actualizados en la última ejecución con cambios.
Intervenciones data/congreso/intervenciones/{recurso}/latest.json Última versión de un recurso de intervenciones detectado o añadido mediante INTERVENCIONES_EXTRA_URLS.

Estructura de los JSON

Índice de votaciones

{
  "source": "https://www.congreso.es/es/opendata/votaciones",
  "generated_at": "2026-06-16T10:00:00+00:00",
  "total_votes": 123,
  "last_run": {
    "checked_at": "2026-06-16T10:00:00+00:00",
    "discovered_links": 123,
    "changed_votes": 2
  },
  "votes": {
    "leg15-sesion185-20260611-votacion001": {
      "id": "leg15-sesion185-20260611-votacion001",
      "path": "data/congreso/votaciones/leg15/sesion185/20260611/votacion001.json",
      "source_url": "https://www.congreso.es/.../VOT_20260611145700.json",
      "legislature": "Leg15",
      "session": "Sesion185",
      "date": "20260611",
      "vote": "Votacion001"
    }
  }
}

Detalle de un recurso

{
  "metadata": {
    "id": "...",
    "source_url": "...",
    "captured_at": "2026-06-16T10:00:00+00:00"
  },
  "data": {
    "...": "Respuesta oficial del Congreso"
  }
}

El bloque metadata lo genera este repositorio. El bloque data conserva la estructura oficial del Congreso, por lo que sus campos pueden variar según el tipo de recurso.

Qué información hay disponible

Votaciones

Votaciones nominales y recursos JSON oficiales publicados por sesión plenaria.

  • Legislatura, sesión, fecha y número de votación.
  • URL oficial y nombre de fichero oficial.
  • Respuesta oficial completa dentro de data.

Iniciativas

Datasets publicados por el Congreso en la sección de iniciativas.

  • Iniciativas legislativas aprobadas.
  • Proyectos de ley.
  • Proposiciones de ley.
  • Propuestas de reforma de estatuto y otros datasets oficiales que aparezcan.

Intervenciones

Recursos de intervenciones detectados desde el buscador oficial.

  • Enlaces JSON, CSV o XML si aparecen expuestos.
  • Recursos añadidos manualmente con INTERVENCIONES_EXTRA_URLS.
  • Contenido normalizado como JSON con data o data_raw.

Ejemplos de uso

JavaScript: obtener el índice de votaciones y cargar una votación

const base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';

const index = await fetch(base + 'data/congreso/votaciones/index.json')
  .then(response => response.json());

const votes = Object.values(index.votes || {});
const latestVote = votes.at(-1);

const detail = await fetch(base + latestVote.path)
  .then(response => response.json());

console.log(detail.metadata);
console.log(detail.data);

PHP: leer iniciativas

<?php
$base = 'https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/';

$index = json_decode(
    file_get_contents($base . 'data/congreso/iniciativas/index.json'),
    true
);

foreach ($index['datasets'] ?? [] as $dataset) {
    $json = json_decode(file_get_contents($base . $dataset['latest_path']), true);
    echo $dataset['official_name'] . PHP_EOL;
}

curl -L https://raw.githubusercontent.com/jalonsomerchan/congreso-opendata/main/data/congreso/votaciones/index.json
